Pytorch

# Environment

$ export PATH=/home/nightly/install/conda/envs/pytorch-py35/bin:$PATH

(pytorch only supports python 3.5 and does not provide good support to python 2.7)

# Compile

In pytorch/pytorch, do:

$ python setup.py install --user

In pytorch/vision, do:

$ python setup.py install --user

# Run

In pytorch/examples/imagenet, do:

$ pip install --user -r requirements.txt

You will see packages generated in ~/.local/lib/python3.5/site-packages

To run resnet50, run:

$ srun -p P100 -n 8 --exclusive python main.py -b 128 --epochs 1 -a resnet50 /data/imagenet

1) It will use all available GPUs unless otherwise specified by CUDA_VISIBLE_DEVICES
2) It will only output batch time, to get "image/sec", divide batch size (default 256) by batch time
3) For more options, see README into that folder
4) Default batch size of 256 causes out of memory error on P100
5) Default epochs is 90 which will run for several hours; minimize running time by setting number of epochs to 1 (--epochs 1) but running time is still long (~45 mins on DGX-1); have not found a way to control the number of iterations
6) Uses data and val in jpeg format and expects directories named data and val under <prefix>/imagenet/; currently not present on dbcluster /raid/dldata/imagenet, so need to create symlinks to train-jpeg and val-jpeg named train and val respectively
