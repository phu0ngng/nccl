## Summary
Briefly describe the change and its purpose.
- Be clear whether the change is for a feature, bug fix or refactor with no functional impact.
- Be clear on problem statement.
Can be up to 2-3 lines long

## Implementation
Describe the implementation at a high level. Things to cover:
- New architecture; New data structures introduced; New API etc
- Describe how different sub-systems and components interact
- Future work needed if applicable.
Can be up to 4-5 lines or longer, but please don't be overly verbose and make sure it's easy to read.

## Testing
What testing was done? How was it verified?

## Tracking
Require a nvbugs, Jira or GitHub issue to track the code change.
